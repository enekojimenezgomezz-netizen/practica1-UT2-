# Práctica 1 - UT2: HTML5

Ejercicios 1 a 7 de Lenguaje HTML. El ejercicio 8 se omite.

Abre `index.html` en un navegador para acceder a los ejercicios. Descarga el repositorio completo para conservar las rutas a los recursos. GitHub muestra el código de los HTML; para ver las páginas, ábrelas localmente.

- `ejercicio1.html`: receta de tarta de manzana.
- `ejercicio2.html`: tabla con cabecera, cuerpo y pie.
- `ejercicio3.html`: formulario de alquiler de coches.
- `ejercicio4.html`: blog con etiquetas semánticas y el texto del adjunto.
- `ejercicio5.html`: imagen enlazada, vídeo y audio.
- `Eneko-Jimenez-práctica1-UT2.docx`: respuesta escrita del ejercicio 6 con la explicación de GitHub y el enlace al repositorio.
- `ejercicio6.html`: ficha de producto del ejercicio 7, con el nombre solicitado en el enunciado.
- `recursos/`: imágenes, vídeo y audio utilizados por las páginas.

Sin CSS ni JavaScript. El formulario es una demostración y no tramita reservas.

## Procedencia de los recursos

Las ilustraciones y el sonido son de elaboración propia. La ficha presenta un producto y un testimonio ficticios.

El vídeo «Muévete como un caracol» procede del INTEF, programa Aprendemos en Clan, con cotitularidad del Ministerio de Educación y RTVE:
https://intef.es/aprendemos_episodios/muevete-como-un-caracol/

El antiguo banco multimedia del MEC no estaba accesible al preparar la práctica. El vídeo del INTEF se incluye como alternativa educativa; queda pendiente sustituirlo si se exige un archivo del banco exacto del enunciado.
