Ejercicio 6: GitHub y los repositorios

¿Qué es GitHub?

GitHub es una plataforma en línea que permite alojar proyectos y colaborar con otras personas. Se basa en Git, un sistema de control de versiones que registra los cambios de los archivos y permite consultar versiones anteriores.

¿Qué es un repositorio?

Un repositorio es el lugar donde se guardan los archivos de un proyecto y el historial de sus cambios. Puede incluir código HTML, imágenes y documentación. Puede ser público o privado.

Creación de la cuenta y del repositorio

Pendiente de realizar en la cuenta personal del alumno; no se ha creado una cuenta ni un repositorio remoto.

  1. Acceder a GitHub, registrarse y verificar el correo electrónico.
  2. Iniciar sesión y elegir la opción para crear un repositorio nuevo.
  3. Introducir el nombre practica1-UT2 y una descripción del proyecto.
  4. Elegir su visibilidad y crear el repositorio.
  5. Subir los archivos HTML y la carpeta recursos conservando su estructura.
  6. Guardar los cambios y copiar el enlace del repositorio como evidencia.
